## Quick Command Reference

```bash
# Installation
npm install                 # Install all dependencies

# Development
npm run dev                 # Start dev server (http://localhost:3000)

# Production
npm run build               # Build for production
npm start                   # Start production server

# Code Quality
npm run lint               # Check code quality
npm run format             # Format code
npm run type-check         # Check TypeScript types

# Cleanup
rm -rf node_modules        # Remove dependencies
npm install                # Reinstall everything
```

## Key Concepts

### AI-Powered Content Generation
- Users enter a topic
- AI generates structured content
- Content fills the selected diagram
- Users can regenerate or edit

### 10 Diagram Types
All educational diagrams are implemented:
- SWOT, Fishbone, Venn, Mind Map, Flowchart
- Timeline, Pyramid, Cause-Effect Matrix, Concept Map, T-Chart

### Multi-Role Authentication
- Students: Create and save diagrams
- Teachers: View student progress
- Parents: Monitor learning

### Tech Stack
- React 18, Next.js 14, TypeScript
- Tailwind CSS, Firebase, OpenAI
